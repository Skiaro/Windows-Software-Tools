### 系统工具

*   **7-Zip** | [项目地址](https://github.com/ip7z/7zip) | [官网](https://www.7-zip.org/) - 免费开源的压缩软件，以极高的压缩比和简洁的界面著称，支持 7z、ZIP、RAR 等多种格式。
*   **Everything** | [官网](https://www.voidtools.com/zh-cn/) - 极速本地文件搜索工具，基于 NTFS 文件系统索引，瞬间检索全盘文件。
*   **FileConverter** | [项目地址](https://github.com/Tichau/FileConverter) | [官网](https://file-converter.io/) - 通过右键菜单即可完成文件格式转换与压缩的轻量工具，支持批量处理。
*   **Twinkle Tray** | [项目地址](https://github.com/xanderfrangos/twinkle-tray) | [官网](https://twinkletray.com/) - 在系统托盘中统一调节多台显示器亮度的开源工具，弥补 Windows 原生功能对外接显示器支持的不足。

### 多媒体与下载

*   **Bili23 Downloader** | [项目地址](https://github.com/ScottSloan/Bili23-Downloader) | [官网](https://bili23.scott-sloan.cn/)- 拥有现代 UI 的跨平台 B 站视频下载工具，支持视频、番剧、电影、纪录片等全部 B 站 URL 类型。
*   **PotPlayer** | [官网](https://potplayer.daum.net/) - 韩国 Kakao 公司推出的全能视频播放器，内置强大解码器，支持单帧播放、变速、多声道音频等丰富功能。
*   **OBS Studio** | [项目地址](https://github.com/obsproject/obs-studio) | [官网](https://obsproject.com/) - 免费开源的直播推流与屏幕录制软件，支持多场景切换、实时混音与视频合成。
*   **yt-dlg** | [项目地址](https://github.com/yt-dlg/yt-dlg) | [官网](https://oleksis.github.io/youtube-dl-gui/) - 基于 youtube-dl 的跨平台图形化下载器，支持海量视频网站，提供 Windows / macOS / Linux 版本。

### 办公与教育

*   **Mocreak** | [项目地址](https://github.com/OdysseusYuan/Mocreak) | [官网](https://www.mocreak.com/)- 一键自动化下载、安装、部署正版 Office 的办公增强工具，完全免费、无广告。
*   **Watt Toolkit** | [项目地址](https://github.com/BeyondDimension/SteamTools) | [官网](https://steampp.net/) - 原名 Steam++，开源跨平台的多功能游戏工具箱与网络加速工具，支持 Steam 社区访问及 GitHub 加速。
*   **tchMaterial-parser** | [项目地址](https://github.com/happycola233/tchMaterial-parser) - 国家中小学智慧教育平台电子课本下载工具，帮助获取电子课本 PDF 并下载。
*   **Microsoft Activation Scripts (MAS)** | [项目地址](https://github.com/massgravel/Microsoft-Activation-Scripts) | [官网](https://massgrave.dev/) - 开源 Windows / Office 激活脚本，集成 HWID、Ohook、TSforge、KMS38 及在线 KMS 等多种激活方式。
*   **Dism-Multi-language** | [项目地址](https://github.com/Chuyu-Team/Dism-Multi-language) - Dism++ 的多语言支持与 BUG 反馈仓库，Dism++ 是 Windows 系统精简、优化与映像管理工具。

### 文件处理

*   **LocalSend** | [项目地址](https://github.com/localsend/localsend) | [官网](https://localsend.org/) - 开源、跨平台的局域网文件传输工具，无需互联网连接，可在附近设备间安全分享文件与消息。
*   **Stirling-PDF** | [项目地址](https://github.com/Stirling-Tools/Stirling-PDF) - 功能强大的本地托管 PDF 处理工具，支持编辑、合并、拆分、转换、OCR 等多种操作。
